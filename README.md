## Related Projects

### Forum scripts collection

The [Leapmotor Friends and Drivers Forum scripts collection](https://github.com/synb10se/lpmff/blob/main/README.md)
organizes automation scripts by project, programming language, configuration,
and documentation.

### KBA statistics

[KBA statistics](https://github.com/synb10se/lpmff/blob/main/kbastatistiken/Readme.md)
turns CSV exports from Germany's vehicle-registration statistics portal into
browser-viewable HTML reports. A PHP interface uploads the CSV and previews
the output generated by a Python script. Saving a report requires a separate
password-protected confirmation; the generated HTML can then be published
independently of PHP and Python.

### Improvement suggestions

The [improvement suggestions application](https://github.com/synb10se/lpmff/blob/main/sfi_LeapOS/README.md)
is a PHP/Apache tool for collecting and reviewing suggestions, stored in a JSON
file. It provides German and English interfaces, an administrative workflow,
and CSV or Excel-compatible exports for reviewed entries. Optional free-text
translation uses a LibreTranslate service.
