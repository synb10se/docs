## Related Projects

### Forum scripts collection

The [Leapmotor Friends and Drivers Forum scripts collection](https://github.com/synb10se/lpmff/blob/main/README.md)
collects scripts and web applications by project. The collection overview is
available in [German](lpmff/README.md) and [English](lpmff/README.en.md).

### KBA statistics

[KBA statistics](kbastatistiken/README.md) fetches registration data from the
German Federal Motor Transport Authority (KBA) ArcGIS service and generates
browser-viewable HTML reports. The documentation is available in
[German](kbastatistiken/README.md) and [English](kbastatistiken/README.en.md).

### Leapmotor app quick guide

The static [Leapmotor app guide](manual_app/README.md) documents the companion
app for Android and iOS. Read the overview in [German](manual_app/README.md) or
[English](manual_app/README.en.md).

### Leapmotor B10 quick guide

The static [B10 guide](manual_b10/README.md) covers vehicle controls and the
LeapOS infotainment system. Read the overview in [German](manual_b10/README.md)
or [English](manual_b10/README.en.md).

### Improvement suggestions

The [improvement suggestions application](sfi_LeapOS/README.md) is a PHP/Apache
tool for collecting and reviewing suggestions. Read the deployment and
workflow documentation in [German](sfi_LeapOS/README.md) or
[English](sfi_LeapOS/README.en.md).
