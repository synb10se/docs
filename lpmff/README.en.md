# Leapmotor Friends and Drivers Forum project collection

This repository collects scripts and web applications for the Leapmotor
Friends and Drivers Forum. Projects are organized by purpose; each project
directory contains its own implementation, configuration and documentation.

## Projects

| Project | Description | Documentation |
|---|---|---|
| [`kbastatistiken/`](https://github.com/synb10se/lpmff/tree/main/kbastatistiken) | Fetches KBA new-registration data and generates HTML statistics. | [German](../kbastatistiken/README.md) · [English](../kbastatistiken/README.en.md) |
| [`manual_app/`](https://github.com/synb10se/lpmff/tree/main/manual_app) | Unofficial quick guide to the Leapmotor app for Android and iOS. | [German](../manual_app/README.md) · [English](../manual_app/README.en.md) |
| [`manual_b10/`](https://github.com/synb10se/lpmff/tree/main/manual_b10) | Unofficial quick guide to the Leapmotor B10 and LeapOS. | [German](../manual_b10/README.md) · [English](../manual_b10/README.en.md) |
| [`sfi_LeapOS/`](https://github.com/synb10se/lpmff/tree/main/sfi_LeapOS) | PHP application for collecting and managing LeapOS improvement suggestions. | [German](../sfi_LeapOS/README.md) · [English](../sfi_LeapOS/README.en.md) |
